## Number Series

> Original practice questions - newly written for classroom use, not copied from any source.    Answers distributed across A-D; every item independently checked.

*Directions:  Work out the rule linking the numbers, then choose the value that continues the sequence.*

**Q1.** Which number comes next?   3, 7, 11, 15, 19, ...

- **(A)** 23
- **(B)** 25
- **(C)** 21
- **(D)** 27

**Answer:** Option A  (23)

**Explanation:** Each term increases by 4 (an arithmetic step). 19 + 4 = 23.

---

**Q2.** Which number comes next?   5, 10, 20, 40, 80, ...

- **(A)** 140
- **(B)** 160
- **(C)** 180
- **(D)** 200

**Answer:** Option B  (160)

**Explanation:** Each term is double the one before it. 80 x 2 = 160.

---

**Q3.** Which number comes next?   2, 5, 11, 23, 47, ...

- **(A)** 83
- **(B)** 91
- **(C)** 95
- **(D)** 99

**Answer:** Option C  (95)

**Explanation:** Each term is twice the previous term plus one (x2 + 1). 47 x 2 + 1 = 95.

---

**Q4.** Which number comes next?   100, 91, 82, 73, 64, ...

- **(A)** 52
- **(B)** 58
- **(C)** 60
- **(D)** 55

**Answer:** Option D  (55)

**Explanation:** Each term decreases by 9. 64 - 9 = 55.

---

**Q5.** Which number comes next?   1, 4, 9, 16, 25, ...

- **(A)** 36
- **(B)** 30
- **(C)** 42
- **(D)** 49

**Answer:** Option A  (36)

**Explanation:** These are consecutive perfect squares: 1, 4, 9, 16, 25 = 1^2 to 5^2. Next is 6^2 = 36.

---

**Q6.** Which number comes next?   6, 11, 21, 36, 56, ...

- **(A)** 76
- **(B)** 81
- **(C)** 86
- **(D)** 91

**Answer:** Option B  (81)

**Explanation:** The amount added grows by 5 each time: +5, +10, +15, +20, +25. 56 + 25 = 81.

---

**Q7.** Which number comes next?   81, 27, 9, 3, ...

- **(A)** 3
- **(B)** 2
- **(C)** 1
- **(D)** 0

**Answer:** Option C  (1)

**Explanation:** Each term is the previous one divided by 3. 3 / 3 = 1.

---

**Q8.** Which number comes next?   4, 9, 19, 39, 79, ...

- **(A)** 149
- **(B)** 155
- **(C)** 160
- **(D)** 159

**Answer:** Option D  (159)

**Explanation:** Each term is twice the previous plus one (x2 + 1). 79 x 2 + 1 = 159.

---

**Q9.** Which number comes next?   7, 8, 15, 23, 38, ...

- **(A)** 61
- **(B)** 58
- **(C)** 51
- **(D)** 66

**Answer:** Option A  (61)

**Explanation:** From the third term on, each number is the sum of the two before it: 7+8=15, 8+15=23, 15+23=38, 23+38=61.

---

**Q10.** Which number comes next?   2, 6, 12, 20, 30, ...

- **(A)** 40
- **(B)** 42
- **(C)** 44
- **(D)** 46

**Answer:** Option B  (42)

**Explanation:** The gaps grow by 2 each step: +4, +6, +8, +10, +12 (this is n x (n+1)). 30 + 12 = 42.

## Letter & Symbol Series

*Directions:  Identify the letter (and number) pattern, then choose the group that continues the series.*

**Q1.** Which group comes next?   B, D, F, H, J, ...

- **(A)** L
- **(B)** N
- **(C)** K
- **(D)** M

**Answer:** Option A  (L)

**Explanation:** The letters advance by two, taking every second letter: B, D, F, H, J, L. Next is L.

---

**Q2.** Which group comes next?   A, C, E, G, ...

- **(A)** H
- **(B)** I
- **(C)** J
- **(D)** K

**Answer:** Option B  (I)

**Explanation:** Every second letter of the alphabet: A, C, E, G, I. Next is I.

---

**Q3.** Which group comes next?   Z, X, V, T, ...

- **(A)** S
- **(B)** Q
- **(C)** R
- **(D)** P

**Answer:** Option C  (R)

**Explanation:** The letters move backward by two: Z, X, V, T, R. Next is R.

---

**Q4.** Which group comes next?   AZ, BY, CX, DW, ...

- **(A)** FV
- **(B)** EU
- **(C)** DV
- **(D)** EV

**Answer:** Option D  (EV)

**Explanation:** The first letters go forward (A, B, C, D, E) while the second letters go backward (Z, Y, X, W, V). Next pair is EV.

---

**Q5.** Which group comes next?   AB, DE, GH, JK, ...

- **(A)** MN
- **(B)** LM
- **(C)** NO
- **(D)** OP

**Answer:** Option A  (MN)

**Explanation:** Each pair starts three letters after the last pair began: AB, DE, GH, JK, MN. Next is MN.

---

**Q6.** Which group comes next?   ACE, BDF, CEG, ...

- **(A)** DEF
- **(B)** DFH
- **(C)** EFG
- **(D)** DFG

**Answer:** Option B  (DFH)

**Explanation:** Every letter shifts one place forward from the group before it: A->B->C->D, C->D->E->F, E->F->G->H. Next is DFH.

---

**Q7.** Which group comes next?   Z1, Y2, X3, W4, ...

- **(A)** U5
- **(B)** W5
- **(C)** V5
- **(D)** V4

**Answer:** Option C  (V5)

**Explanation:** The letters count down Z, Y, X, W, V while the numbers count up 1, 2, 3, 4, 5. Next is V5.

---

**Q8.** Which group comes next?   CDE, FGH, IJK, ...

- **(A)** MNO
- **(B)** KLM
- **(C)** LNP
- **(D)** LMN

**Answer:** Option D  (LMN)

**Explanation:** Each block is three consecutive letters, continuing with no gap: C-E, F-H, I-K, then L-N. Next is LMN.

---

**Q9.** Which group comes next?   A1B, C2D, E3F, ...

- **(A)** G4H
- **(B)** F4G
- **(C)** H4I
- **(D)** G3H

**Answer:** Option A  (G4H)

**Explanation:** The outer letters form consecutive pairs A-B, C-D, E-F, G-H, and the middle number counts 1, 2, 3, 4. Next is G4H.

---

**Q10.** Which group comes next?   BZ, DY, FX, HW, ...

- **(A)** IV
- **(B)** JV
- **(C)** KV
- **(D)** JU

**Answer:** Option B  (JV)

**Explanation:** The first letters advance by two (B, D, F, H, J) and the second letters step back one (Z, Y, X, W, V). Next is JV.

## Logical Deduction

> Original practice questions - newly written for classroom use, not copied from any source.    Answers spread across A-D; every item independently checked.

*Directions:  Treat the statements as true even where they differ from common facts. Decide which of the two conclusions logically follows.*

**Q1.** Statements:  (1) All roses are flowers.  (2) All flowers are plants.  
Conclusions:  I. All roses are plants.   II. Some plants are roses.  
Which conclusion(s) logically follow?

- **(A)** Only conclusion I follows
- **(B)** Only conclusion II follows
- **(C)** Both conclusions follow
- **(D)** Neither conclusion follows

**Answer:** Option C  (Both conclusions follow)

**Explanation:** Roses are flowers and flowers are plants, so every rose is a plant (I). Since all roses are plants and roses exist, some plants are roses (II). Both follow.

---

**Q2.** Statements:  (1) Some cats are black.  (2) All black things are dark.  
Conclusions:  I. Some cats are dark.   II. All cats are dark.  
Which conclusion(s) logically follow?

- **(A)** Only conclusion I follows
- **(B)** Only conclusion II follows
- **(C)** Both conclusions follow
- **(D)** Neither conclusion follows

**Answer:** Option A  (Only conclusion I follows)

**Explanation:** The black cats are dark, so some cats are dark (I). But only some cats are black, so we cannot say all cats are dark (II fails).

---

**Q3.** Statements:  (1) All doctors are graduates.  (2) Some graduates are wealthy.  
Conclusions:  I. Some doctors are wealthy.   II. Some graduates are doctors.  
Which conclusion(s) logically follow?

- **(A)** Only conclusion I follows
- **(B)** Only conclusion II follows
- **(C)** Both conclusions follow
- **(D)** Neither conclusion follows

**Answer:** Option B  (Only conclusion II follows)

**Explanation:** Since all doctors are graduates and doctors exist, some graduates are doctors (II). The wealthy graduates need not include any doctor, so I does not follow.

---

**Q4.** Statements:  (1) Some pens are red.  (2) Some red things are pencils.

- **(B)** Only conclusion II follows
- **(C)** Both conclusions follow
- **(D)** Neither conclusion follows

**Answer:** Option D  (Neither conclusion follows)

**Explanation:** Two 'some' statements cannot be chained - the red pens and the red pencils may be entirely different things. Neither follows.

---

**Q5.** Statements:  (1) All mangoes are fruits.  (2) No fruit is a vegetable.  
Conclusions:  I. No mango is a vegetable.   II. Some fruits are mangoes.  
Which conclusion(s) logically follow?

- **(A)** Only conclusion I follows
- **(B)** Only conclusion II follows
- **(C)** Both conclusions follow
- **(D)** Neither conclusion follows

**Answer:** Option C  (Both conclusions follow)

**Explanation:** Mangoes are fruits and no fruit is a vegetable, so no mango is a vegetable (I). Since all mangoes are fruits and mangoes exist, some fruits are mangoes (II). Both follow.

---

**Q6.** Statements:  (1) All engineers are logical.  (2) Some logical people are artists.  
Conclusions:  I. Some engineers are artists.   II. Some artists are engineers.  
Which conclusion(s) logically follow?

- **(A)** Only conclusion I follows

---

**Q7.** Statements:  (1) No dogs are cats.  (2) Some cats are pets.

## Statement & Assumption

> Original practice questions - newly written for classroom use, not copied from any source.    Answers spread across A-D; every item independently checked.

*Directions:  An assumption is something taken for granted in the statement. Decide which of the two assumptions is implicit in the statement.*

**Q1.** Statement:  “Please submit the form before the deadline to avoid a late fee.”  
Assumptions:  I. A late fee applies to submissions made after the deadline.   II. No one ever submits the form on time.  
Which assumption(s) is / are implicit?

- **(A)** Only assumption I is implicit
- **(B)** Only assumption II is implicit
- **(C)** Both assumptions are implicit
- **(D)** Neither assumption is implicit

**Answer:** Option A  (Only assumption I is implicit)

**Explanation:** The advice to submit before the deadline 'to avoid a late fee' takes for granted that a late fee exists (I). It does not assume no one submits on time (II is absurd).

---

**Q2.** Statement:  “Our online course is so simple that even a complete beginner can finish it without help.”  
Assumptions:  I. Beginners are not intelligent.   II. The course is meant to be usable by beginners.  
Which assumption(s) is / are implicit?

- **(A)** Only assumption I is implicit
- **(B)** Only assumption II is implicit
- **(C)** Both assumptions are implicit
- **(D)** Neither assumption is implicit

**Answer:** Option B  (Only assumption II is implicit)

**Explanation:** Evidence that more streetlights actually coincide with far fewer night accidents directly supports the claimed link, strengthening the argument.

**Q2.** Argument: This restaurant must be excellent, because it is always crowded. Which statement, if true, most WEAKENS the argument?

- **(B)** It is crowded only because it is the cheapest option nearby, not because the food is good.
- **(C)** It has been open for ten years.
- **(D)** It serves many cuisines.

**Answer:** Option B

**Explanation:** If the crowds come from low prices rather than quality, being crowded no longer implies the food is excellent - this undermines the argument.

- **(D)** Headphones are inexpensive.

**Answer:** Option C

**Explanation:** If those students were already weaker beforehand, their lower scores may be due to prior ability, not the music - breaking the argument's cause-and-effect claim.
